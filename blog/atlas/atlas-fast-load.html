What the integrity boundary does
The definition file and executable modules are hash-locked. The PGN is read and validated, not looked up in a second corpus. The grader runs in its own Worker and does not read the Oracle’s pass/fail results. Editing the PGN changes the imported record; it must still satisfy the locked grammar and integrity checks.
The JSON contains definitions only. Every concrete defense is stored as ordinary PGN movetext with readable NODE anchors. Positions, piece identities, classes, and usage indexes are rebuilt in memory from that text. Nothing missing from the PGN is recovered from the dictionary.
Checksums are tamper-evidence against a known checkpoint, not a digital signature or protection against rewriting the verifier itself.
