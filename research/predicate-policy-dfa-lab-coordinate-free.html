Binding grammar

predicate-policy/v2

The JSON is not decorative configuration. It is the executable grammar that binds each visible card and every transition.

policy ::= {
  schema, entry,
  outcomes, budgets,
  routines[], states[]
}

routine ::= {
  id, label?, entry
}

state ::= {
  id, routine, kind,
  description?, ...kind_fields
}

kind ::= push_initial | pop |
  inspect | search | call |
  return | accept | reject

inspect.rules are tested top → bottom.
The first matching rule determines one transition.

when ::= {
  side?: "my" | "their",
  any?: string[],
  all?: string[],
  none?: string[]
}

search ::= {
  predicates: string[],
  closure: {
    mode: "first" | "all" |
          "one_each",
    count?: integer
  },
  on: { pushed, none }
}

call ::= {
  routine, return_to,
  resume_current?: boolean
}

RETURN pops the control frame.
POP never crosses its active frame boundary.
All state references use globally unique IDs.
DeterminismInspect rules and search predicates are ordered. First-match semantics remove ambiguity.
ClosureEvery search state declares whether it keeps the first N, all matches, or one match per predicate.
SubroutinesCALL preserves caller thoughts below a boundary; RETURN resumes at return_to.
Coordinate-freeConditions refer only to side labels and predicate strings supplied by the oracle.
